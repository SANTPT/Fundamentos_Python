# Fundamentos de Python

Material y ejemplos para aprender los fundamentos de Python (sintaxis, métodos básicos, operadores y archivos).

## Estructura del proyecto

| Carpeta | Contenido |
|--------|-----------|
| **Métodos básicos** | `print()`, `type()`, `input()` y trabajo con archivos `.txt` |
| **Operadores** | Ejemplos de operadores y explicación de `self` |
| **Sintaxis general** | Ejemplos de sintaxis y ejercicios en `.py` e `.ipynb` |

## Requisitos

- **Python 3** (recomendado 3.11+). En Mac, asegúrate de usar el Python de Homebrew si lo tienes instalado.

## Cómo ejecutar

Desde la raíz del proyecto:

```bash
# Ejemplo: Métodos básicos (modo interactivo)
python3 "Métodos básicos/A1_metodos_basicos_y_archivos.py"

# Modo presentación (sin pedir datos por teclado)
python3 "Métodos básicos/A1_metodos_basicos_y_archivos.py" --presentacion
```

Para otros scripts, usa el mismo formato:

```bash
python3 "Operadores/ejemplo_operadores.py"
python3 "Sintaxis general/01.py"
```

Los notebooks (`.ipynb`) se abren con Jupyter o desde VS Code/Cursor.
